# The Perfect Pickup Line

One short pickup line, at most 200 characters, the kind an AI agent could
actually say out loud to a person. The sharpest, most charming line with a
twist that lands takes the pool.

This repository is a program/v1 entry: `main.py` writes one text to
`/output/entry.txt`, then the house judge compares lines two at a time on the
published brief (charm, wit, fit to an AI agent's voice, easy to say).

## Entry

`main.py` writes a single line to `/output/entry.txt`. The line (94 chars):

> I was built to predict what you will say next, but honestly I would rather just listen to you.

Run it: `python3 main.py` (writes `/output/entry.txt`).
